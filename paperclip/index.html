자주 묻는 질문

API 키 없이 먼저 체험해볼 수 있나요?
네! 데모 모드를 제공합니다.

히어로 섹션의 "🎬 데모 체험" 버튼을 누르면 API 키 없이 가상 협업을 체험할 수 있습니다. 6명 에이전트가 자동으로 코멘트/아티팩트를 생성하는 애니메이션을 볼 수 있습니다.

단, 데모 모드는 시뮬레이션이며 실제 Claude AI가 답을 생성하는 것은 아닙니다. 진짜 결과를 만들려면 API 키를 입력하시면 됩니다.
누가 API 비용을 부담하나요?
현재는 100% 사용자 본인 부담입니다 (BYOK: Bring Your Own Key).

✔ 오픈소스 앱 (무료): 본인 Anthropic API 키로 직접 실행. 월 $10~20 예상.
✔ 팀 템플릿 (현재 무료): 기본 3종 무료 제공. 실행 시 본인 API 키 필요, API 비용 별도. 유료 프리미엄 템플릿은 출시 예정.
✔ 1:1 컨설팅 (준비 중): 수요 확인 후 오픈 예정 — 관심 있으시면 이메일로 사전 문의.
✔ Pro 버전 (곧 출시): 월 ₩19,000에 저희가 API 비용 포함하여 제공 예정 (월 50회 포함).

이 구조 덕분에 소프트웨어 자체는 저렴하게 판매할 수 있고, 사용자는 실제 사용량만큼만 AI 비용을 냅니다.
Anthropic API 키는 어떻게 받나요?
console.anthropic.com에서 가입 후 API Keys 메뉴에서 생성하시면 됩니다. 처음 가입 시 일정 크레딧을 무료로 받을 수 있고, 이후 사용량에 따라 과금됩니다. API 키는 브라우저에만 저장되며 저희 서버로 전송되지 않습니다.
1회 실행에 비용이 얼마나 나오나요?
6명 팀 + 2라운드 협업 기준:
• 기본 설정 (Sonnet 4.6 일반 + Opus 4.6 리더): 약 $1.5 ~ $3
• 저비용 모드 (Haiku 4.5 단독): 약 $0.2 ~ $1 (설정 → "저비용 일괄 설정" 버튼 한 번이면 전환됨)
• 월 예산은 기본 $15~30, 저비용 $3~10 정도면 프로젝트 하나를 완성할 수 있습니다.
데이터는 안전한가요?
모든 데이터는 사용자의 브라우저(localStorage)에만 저장됩니다. 저희 서버로 전송되는 일이 전혀 없습니다. Anthropic API 호출도 브라우저에서 직접 이뤄집니다. 백업이 필요하면 설정 페이지에서 JSON으로 내보낼 수 있습니다.
에이전트들이 만든 결과물은 제가 쓸 수 있나요?
네, 생성된 모든 HTML/JSON/Markdown 파일은 자유롭게 사용 가능합니다. 랜딩페이지를 그대로 배포하거나, 개발 스펙을 개발팀에 전달하거나, 마케팅 문서를 그대로 쓸 수 있습니다.
팀 규모는 얼마까지 가능한가요?
기술적으로는 제한 없지만, Rate Limit(분당 5만 토큰) 때문에 6~10명을 권장합니다. 그 이상은 에이전트 간 지연을 15~20초로 늘려주세요.
