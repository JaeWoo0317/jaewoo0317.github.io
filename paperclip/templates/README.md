# 📦 JWAY Paperclip 팀 템플릿

검증된 AI 에이전트 팀 템플릿을 한 번에 가져올 수 있습니다.

## 사용 방법

1. JWAY Paperclip 앱에서 **⚙️ 설정** 페이지로 이동
2. **📦 템플릿 → 📥 템플릿 가져오기** 버튼 클릭
3. 아래 템플릿 중 하나의 JSON 파일 선택
4. 에이전트 + 목표 + 이슈가 한 번에 생성됨
5. Anthropic API 키 입력 후 **🤝 협업 Heartbeat** 실행

## 🎁 무료 템플릿

### 1. 스타트업 MVP 팀 (6인)
- **파일**: `01-startup-mvp-team.json`
- **구성**: CEO · CTO · PM · 엔지니어 · 마케터 · 디자이너
- **활용**: 새 서비스 아이디어를 2주 안에 MVP 기획 + 랜딩페이지까지 완성
- **산출물 예시**:
  - 12개월 비즈니스 로드맵 (Markdown)
  - 기술 스택 JSON
  - 페르소나 3종 + MVP 스코프
  - HTML 랜딩페이지
  - 마케팅 실행 계획

### 2. 이커머스 그로스 팀 (5인)
- **파일**: `02-ecommerce-growth-team.json`
- **구성**: 분석가 · 퍼포먼스 마케터 · 카피라이터 · 디자이너 · 리텐션 전략가
- **활용**: 기존 쇼핑몰 매출 2배 성장 계획 수립 및 실행 가이드
- **산출물 예시**:
  - KPI 대시보드 스펙 JSON
  - 광고 카피 20개 + A/B 테스트 매트릭스
  - 크리에이티브 30개 기획안
  - 리텐션 플레이북

### 3. 1인 콘텐츠 크리에이터 팀 (4인)
- **파일**: `03-content-creator-team.json`
- **구성**: 콘텐츠 전략가 · 롱폼 작가 · 크리에이티브 디렉터 · SNS 배포
- **활용**: 유튜브/블로그/뉴스레터 운영자가 혼자서 콘텐츠 공장 돌리기
- **산출물 예시**:
  - 월간 콘텐츠 캘린더
  - 블로그 포스트 (SEO 최적화)
  - 썸네일 카피 + HTML 뉴스레터
  - 플랫폼별 SNS 카피 세트

## 💡 비용 참고

각 템플릿의 **협업 Heartbeat 1회 실행 비용**:
- 스타트업 MVP 팀 (6인, 2라운드): $0.5 ~ $1.5
- 이커머스 그로스 팀 (5인, 2라운드): $0.4 ~ $1.0
- 콘텐츠 크리에이터 팀 (4인, 2라운드): $0.3 ~ $0.8

Anthropic API 사용 비용 기준 (Haiku 4.5 + Opus Advisor 포함).

## 🛠 커스텀 템플릿 만들기

본인 팀을 템플릿으로 저장하려면:
1. 설정 → 📦 템플릿 → **현재 팀을 템플릿으로 저장**
2. 생성된 JSON 파일을 공유하거나 판매 가능
