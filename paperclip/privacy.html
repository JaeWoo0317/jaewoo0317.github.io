개인정보처리방침

최종 업데이트: 2026년 4월 20일 · 발효일: 2026년 4월 20일

🔒 핵심 요약: JWAY Paperclip은 서버를 운영하지 않습니다. 모든 데이터(API 키, 에이전트, 이슈, 대화, 아티팩트)는 사용자 본인의 브라우저(localStorage)에만 저장됩니다. 저희는 사용자 데이터를 수집/저장/전송하지 않습니다.

1. 개요

JWAY Paperclip(이하 "서비스")은 정보통신망 이용촉진 및 정보보호 등에 관한 법률, 개인정보 보호법을 준수하며, 이용자의 개인정보 보호를 위해 최선을 다하고 있습니다.

2. 수집하는 개인정보

서비스는 사용자로부터 어떠한 개인정보도 직접 수집하지 않습니다. 모든 데이터는 사용자의 브라우저에만 저장됩니다.

2-1. 브라우저에 저장되는 정보 (로컬 저장, 서버 전송 없음)

  • Anthropic API 키: 사용자가 직접 입력한 키. localStorage의 jway-paperclip 키에 암호화 없이 평문 저장
  • 회사/에이전트/이슈/목표 데이터: 사용자가 생성한 모든 컨텐츠
  • AI 생성 결과물: 코멘트, 아티팩트(HTML/JSON/MD)
  • 비용 이벤트: API 호출 이력 및 토큰 사용량
  • 비밀번호 해시: localStorage의 jway-paperclip-lock에 SHA-256 해시로 저장

2-2. 외부 API 호출 시 전송되는 정보

서비스를 실행할 때 다음 정보가 사용자 브라우저에서 직접 Anthropic API(api.anthropic.com)로 전송됩니다:

  • API 키 (사용자 본인 것)
  • 시스템 프롬프트 + 사용자 메시지
  • 도구 설정 (웹 검색, Advisor 등)
⚠️ 주의: Anthropic API로 전송되는 데이터는 Anthropic의 개인정보처리방침에 따릅니다. 자세한 내용은 Anthropic Privacy Policy를 확인하세요. 민감한 개인정보(주민번호, 신용카드 등)를 에이전트 프롬프트나 이슈 내용에 입력하지 마세요.

3. 개인정보 수집 방법

서비스는 사용자 계정을 운영하지 않습니다. 회원가입, 로그인, 이메일 수집 등의 절차가 없습니다. 모든 데이터는 사용자 브라우저의 로컬 저장소에만 존재합니다.

4. 개인정보 이용 및 제3자 제공

서비스는 개인정보를 수집하지 않으므로 제3자 제공이 발생하지 않습니다. 다만, 사용자가 명시적으로 Anthropic API를 호출할 때, 입력한 프롬프트는 Anthropic Inc.로 전송됩니다.

5. 쿠키 및 유사 기술

  • localStorage: 서비스 데이터 저장 (필수)
  • sessionStorage: 세션 인증 상태 (필수)
  • Google Analytics (선택): 방문자 통계 수집 목적으로 향후 도입 가능. 도입 시 본 방침을 업데이트합니다.

6. 개인정보 보관 기간

서비스는 개인정보를 수집하지 않으므로 서버 측 보관 기간이 없습니다. 브라우저의 localStorage 데이터는 사용자가 직접 삭제할 때까지 유지됩니다.

7. 이용자의 권리

사용자는 언제든지 다음을 수행할 수 있습니다:

  • ⚙️ 설정 → 📥 전체 백업: 모든 데이터를 JSON으로 다운로드
  • ⚙️ 설정 → 🗑️ 전체 데이터 삭제: 브라우저의 모든 서비스 데이터 제거
  • 브라우저의 개발자 도구(F12) → Application → Local Storage → jway-paperclip 관련 키 직접 삭제

8. 보안

서비스는 서버를 운영하지 않으므로 서버 측 보안 사고가 발생할 수 없습니다. 다만 사용자는 다음 사항에 유의해야 합니다:

  • 공용 컴퓨터에서 사용 후 반드시 데이터 삭제
  • API 키가 localStorage에 평문 저장되므로 다른 스크립트의 접근 가능 (브라우저 보안 정책으로 도메인 격리됨)
  • 비밀번호 설정 기능을 활성화하여 로컬 잠금 권장

9. 아동의 개인정보

서비스는 만 14세 미만 아동의 사용을 권장하지 않습니다. 서비스가 개인정보를 직접 수집하지 않으므로 별도 동의 절차는 없습니다.

10. 고지의 의무
