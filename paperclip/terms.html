이용약관

최종 업데이트: 2026년 4월 20일 · 발효일: 2026년 4월 20일

📌 핵심 요약:
1. JWAY Paperclip은 MIT 라이선스 오픈소스 소프트웨어입니다.
2. AI 기능은 Anthropic API를 사용하며, API 비용은 사용자 본인이 부담합니다.
3. 본 서비스는 "있는 그대로" 제공되며 보증 또는 책임을 지지 않습니다.
4. 팀 템플릿 등 유료 상품은 별도 조건이 적용됩니다.

제1조 (목적)

본 약관은 JWAY Paperclip(이하 "서비스")의 이용 조건 및 절차, 이용자와 서비스 제공자의 권리, 의무 및 책임 사항을 규정함을 목적으로 합니다.

제2조 (정의)

  • "서비스": https://jwaytools.com/paperclip/에서 제공되는 AI 에이전트 협업 플랫폼
  • "이용자": 본 약관에 동의하고 서비스를 이용하는 자
  • "API 키": Anthropic Inc.에서 발급하는 Claude API 인증 키
  • "아티팩트": 서비스에서 AI 에이전트가 생성한 결과 파일 (HTML, JSON, Markdown 등)
  • "팀 템플릿": 에이전트/이슈/목표 구성을 JSON 형태로 저장한 사전 구성

제3조 (약관의 효력 및 변경)

① 본 약관은 서비스에 게시됨으로써 효력이 발생합니다.

② 서비스 제공자는 관련 법령을 위반하지 않는 범위에서 본 약관을 변경할 수 있습니다.

③ 약관이 변경되는 경우 변경사항을 서비스 내에 공지하며, 중요 변경사항은 최소 7일 전에 고지합니다.

제4조 (서비스의 제공)

서비스는 다음 기능을 제공합니다:

  • AI 에이전트 팀 관리 및 협업 시뮬레이션
  • 이슈 관리 및 목표 추적
  • AI가 생성한 아티팩트(코드, 문서) 저장/관리
  • 비용 추적 대시보드
  • 템플릿 Export/Import 기능

제5조 (이용료 및 비용)

5-1. 오픈소스 앱

서비스의 핵심 앱은 무료이며 MIT 라이선스로 제공됩니다.

5-2. Anthropic API 비용 (사용자 부담)

⚠️ 중요: AI 기능을 사용하려면 사용자가 본인의 Anthropic API 키를 입력해야 합니다. Anthropic API 호출에 따른 비용은 전적으로 사용자가 Anthropic Inc.에 직접 지불합니다. 서비스 제공자는 API 비용에 개입하지 않습니다.

5-3. 유료 상품 (선택)

팀 템플릿, 1:1 컨설팅 등 유료 상품은 별도의 결제 조건이 명시됩니다. 구매 전 상품 페이지의 조건을 확인하시기 바랍니다.

제6조 (이용자의 의무)

이용자는 다음 행위를 해서는 안 됩니다:

  • 타인의 API 키를 무단으로 사용하는 행위
  • 서비스를 이용하여 불법적이거나 타인의 권리를 침해하는 컨텐츠를 생성하는 행위
  • 서비스의 취약점을 악용하거나 역공학하는 행위
  • 서비스를 이용하여 스팸, 피싱, 악성코드를 배포하는 행위
  • 서비스를 이용하여 법령 위반, 공서양속 위반 행위
  • 에이전트 프롬프트/이슈에 타인의 개인정보, 기밀정보를 무단 입력하는 행위

제7조 (지적재산권)

7-1. 서비스 코드

서비스의 소스 코드는 MIT 라이선스를 따릅니다. 이용자는 이에 따라 자유롭게 복제, 수정, 배포할 수 있습니다.

7-2. 이용자가 생성한 컨텐츠

이용자가 서비스를 통해 생성한 아티팩트, 이슈 내용, 코멘트, 템플릿 등 모든 컨텐츠의 소유권은 이용자 본인에게 귀속됩니다.

7-3. AI 생성물의 저작권

Anthropic Claude가 생성한 결과물의 저작권은 Anthropic Inc.의 이용 약관을 따르며, 일반적으로 사용자가 상업적 사용 권한을 가집니다. 정확한 권리 사항은 Anthropic Commercial Terms를 참조하세요.

제8조 (서비스의 중단)

서비스 제공자는 다음의 경우 사전 공지 없이 서비스를 중단할 수 있습니다:

  • GitHub Pages 등 호스팅 플랫폼의 장애
  • Anthropic API의 장애 또는 정책 변경
  • 기술적 유지보수 필요 시
  • 천재지변, 전쟁 등 불가항력

제9조 (면책 조항)

⚠️ 매우 중요: 본 서비스는 "있는 그대로(AS IS)" 제공됩니다.

서비스 제공자는 다음에 대해 어떠한 보증이나 책임도 지지 않습니다:

  • AI가 생성한 결과물의 정확성, 적법성, 유용성, 상업적 가치
  • AI 생성 결과물을 이용한 의사결정의 결과 (사업, 투자, 의료, 법률 등)
  • API 비용 초과, 예산 초과로 인한 손실
  • 데이터 손실 (브라우저 저장소 제한, 브라우저 삭제 등)
  • 서비스 중단으로 인한 직·간접적 손해
  • 타사 서비스(Anthropic, GitHub 등)의 장애로 인한 손해

AI 결과물은 반드시 전문가의 검증을 거쳐 사용하시기 바랍니다. 특히 법률, 의료, 재무 관련 의사결정에는 AI 출력을 단독으로 신뢰하지 마세요.

제10조 (책임의 제한)

서비스 제공자의 책임은 다음으로 제한됩니다:

  • 무료 서비스: 책임 없음
  • 유료 상품: 해당 상품의 결제 금액을 한도로 함

제11조 (분쟁 해결)

본 약관의 해석 및 분쟁에 대해서는 대한민국 법령을 적용하며, 서울중앙지방법원을 관할 법원으로 합니다.
