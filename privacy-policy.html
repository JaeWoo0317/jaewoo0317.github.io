개인정보처리방침

최종 업데이트: 2026년 10월 25일 · 시행일: 2026년 4월 24일

처리 방식 요약: 기본 계산기의 입력값은 브라우저에서 계산합니다. QR 생성은 입력 내용을 QRServer로 전송하며 환율은 외부 API를 조회합니다. 문의 이메일과 Paperclip은 별도 외부 처리가 있으므로 아래 범위를 확인하세요.

1. 적용 범위

이 안내는 jwaytools.com의 계산 도구와 콘텐츠 페이지에 적용됩니다. 별도 AI 실험 도구인 Paperclip의 개인정보 안내에는 AI API, 브라우저 저장소와 대기 신청 폼의 처리 범위가 추가로 설명되어 있습니다.

2. 계산기 입력값

연봉·소득세·대출·예적금, 날짜·나이·BMI, 글자수·퍼센트·단위·색상·타이머·랜덤 도구는 입력값을 계산 요청으로 외부 서버에 보내는 기능을 사용하지 않습니다. 회원 계정을 만들지 않으며 기본 계산기 입력값을 JWAY 서버에 저장하는 기능도 없습니다. 브라우저의 자동 완성이나 세션 복원 동작은 별개입니다.

3. 외부 API

  • QRServer: 전송 동의 후 QR 생성을 누르면 현재 탭의 입력 내용 전체가 api.qrserver.com에 전달됩니다. URL·텍스트·Wi-Fi 정보·연락처가 포함될 수 있습니다. 민감한 정보는 입력하지 않는 것을 권합니다. 외부 서비스의 로그와 보관 정책은 QRServer 개인정보 안내를 확인하세요.
  • ExchangeRate-API: 환율 계산기를 열면 open.er-api.com에서 USD 기준 환율표를 요청합니다. 입력 금액은 요청에 포함하지 않습니다. 접속 IP 등 요청 정보는 외부 서비스에서 처리할 수 있습니다. 서비스 이용·개인정보 조건을 확인하세요.

4. 브라우저 저장소

계산기 공통 기능은 최근 방문한 도구의 경로를 localStorage의 jway_recent_tools에 저장해 관련 도구를 표시합니다. 계산에 입력한 금액·생년월일·텍스트를 이 항목에 저장하지 않습니다. 사이트 데이터를 삭제하면 최근 도구 기록도 삭제됩니다. Paperclip은 프로젝트와 API 키 등을 별도 저장하므로 해당 안내를 확인하세요.

5. 문의 이메일

운영자에게 이메일을 보내면 발신 이메일 주소, 이름 등 메일에 포함한 정보와 문의 내용·첨부파일이 메일 서비스를 통해 운영자에게 전달됩니다. 답변과 오류 확인에 필요한 내용만 보내고 주민등록번호, 계좌 비밀번호, API 키 등은 보내지 마세요. 문의 정보의 열람·정정·삭제 요청은 아래 운영자 이메일로 보낼 수 있습니다.

6. 호스팅·글꼴·광고·분석

GitHub Pages 호스팅 및 Google Fonts 등 외부 리소스를 불러오는 과정에서 IP 주소, 접속 시각, 브라우저 정보 등 요청 정보가 해당 제공자에게 전달될 수 있습니다. IP 주소를 일률적으로 비개인정보라고 보지 않습니다. 검색 노출·클릭 통계는 Search Console과 네이버 서치어드바이저에서 확인합니다. Paperclip에는 Google Analytics 코드가 포함되어 있습니다.

사이트에는 Google AdSense 검증용 코드가 포함되어 있으며, 코드 존재가 광고 게재 승인이나 실제 광고 노출을 뜻하지 않습니다. 광고 서비스가 실행되는 페이지에서는 쿠키·기기 정보 등을 처리할 수 있습니다. Google 파트너 사이트의 정보 처리 안내와 Google 광고 설정을 확인하세요. 카카오 애드핏이 실행되는 페이지의 처리는 카카오 광고 정책을 따릅니다.

7. 보관과 삭제

JWAY는 기본 계산기 입력값을 서버에 보관하지 않습니다. 브라우저 저장소는 이용자가 사이트 데이터를 지울 때까지 남을 수 있습니다. 문의 메일은 답변·후속 확인 과정에서 운영자의 메일함에 남을 수 있으므로 삭제를 원하면 문의해 주세요. 외부 제공자의 로그·쿠키·API 요청 보관 기간은 각 제공자의 현행 정책을 확인해야 하며 이 페이지에서 임의의 고정 기간을 보장하지 않습니다.

8. 이용자의 선택

QR 전송에 동의하지 않으면 생성 요청을 보내지 않습니다. 브라우저의 개인정보 설정에서 쿠키와 사이트 저장소를 삭제하거나 제한할 수 있습니다. 저장소를 삭제하면 최근 도구 기록과 Paperclip의 로컬 프로젝트가 사라질 수 있으므로 필요한 자료를 먼저 확인하세요. 외부 서비스의 정보 처리에 관한 요청은 해당 제공자의 안내도 함께 확인하세요.

9. 보안상 주의

사이트와 외부 API는 HTTPS 주소를 사용합니다. 이것이 입력 내용의 모든 보관·접근 위험을 없앤다는 뜻은 아닙니다. 공유 기기에 민감한 정보를 남기지 마세요. 특히 Paperclip API 키는 같은 사이트의 스크립트가 접근할 수 있는 브라우저 저장소에 보관되므로 별도 안내의 위험을 확인해야 합니다.

10. 외부 링크

연결된 외부 사이트는 별도의 개인정보처리방침을 적용합니다. 이동한 사이트에서 입력이나 결제를 하기 전에 해당 안내를 확인하세요.

11. 수정 내역

2026-10-25: 외부 전송이 전혀 없다는 기존의 포괄적 설명을 정정하고 QR API, 환율 조회, 최근 도구 저장, 문의 이메일과 Paperclip의 처리 범위를 구분했습니다. 확인되지 않은 쿠키·접속 로그의 고정 보관 기간을 삭제했습니다.
