개인정보처리방침

최종 업데이트: 2026년 4월 24일 · 시행일: 2026년 4월 24일

핵심 요약: JWAY는 사용자 개인정보를 직접 수집하지 않습니다. 모든 계산은 사용자 브라우저에서 이루어지며 외부로 전송되지 않습니다. 단, 광고 게재(Google AdSense, 카카오 애드핏)와 사이트 분석을 위해 일부 쿠키가 사용될 수 있습니다.

1. 개요

JWAY(이하 "사이트", https://jwaytools.com)는 사용자의 개인정보를 매우 중요하게 생각하며, 「개인정보 보호법」을 비롯한 관련 법령을 준수합니다. 본 방침은 사이트가 어떤 정보를 어떻게 수집·이용하며, 사용자의 권리를 어떻게 보호하는지 안내합니다.

2. 수집하는 개인정보

2-1. 사이트가 직접 수집하지 않는 정보

JWAY는 다음 정보를 직접 수집하지 않습니다:

  • 이름, 이메일, 전화번호 등 식별 정보
  • 주소, 직업, 소득 등 인적사항
  • 회원가입 정보 (회원가입 기능 자체가 없음)
  • 도구 사용 시 입력한 데이터 (키, 몸무게, 연봉, 텍스트 등)

모든 계산은 사용자 브라우저(클라이언트 사이드) 내에서만 처리되며, 입력한 데이터는 서버로 전송되거나 어디에도 저장되지 않습니다. 페이지를 닫으면 모든 입력값은 즉시 사라집니다.

2-2. 자동 수집되는 정보 (제3자 서비스에 의함)

사이트는 다음 제3자 서비스를 통해 일부 비개인 정보를 자동으로 수집할 수 있습니다:

  • 접속 로그: GitHub Pages 호스팅에 의한 IP 주소, 접속 시각, 사용 브라우저 정보 (서버 보안 및 트래픽 분석 목적)
  • 광고 쿠키: Google AdSense, 카카오 애드핏의 광고 게재를 위한 쿠키
  • 분석 도구: Google Search Console, 네이버 서치어드바이저의 검색 통계 데이터

3. Google AdSense 광고 정책

JWAY는 운영비용 충당을 위해 Google AdSense를 통한 광고를 게재합니다. 이와 관련하여 다음 사항을 안내드립니다:

3-1. 제3자 광고 사업자로서의 Google

  • Google은 제3자 공급업체로서 사용자가 본 사이트를 방문한 기록을 바탕으로 쿠키를 사용하여 광고를 게재합니다.
  • Google은 DoubleClick DART 쿠키를 사용해 사용자가 본 사이트 및 다른 사이트에 방문한 정보를 바탕으로 맞춤형 광고를 표시합니다.
  • 사용자는 Google 광고 정책 페이지에서 DART 쿠키 사용을 거부할 수 있습니다.

3-2. 사용자의 광고 설정 권한

사용자는 Google 광고 설정 페이지(https://www.google.com/settings/ads)에서 다음을 직접 관리할 수 있습니다:

  • 맞춤 광고 설정 변경
  • 특정 광고주의 광고 차단
  • 맞춤 광고 완전 비활성화

3-3. 카카오 애드핏

JWAY는 일부 페이지에 카카오 애드핏 광고를 게재할 수 있습니다. 카카오 애드핏의 광고 정책은 카카오 광고 정책을 참고하시기 바랍니다.

4. 쿠키(Cookie) 정책

JWAY 자체는 쿠키를 사용하지 않습니다. 단, 사이트에 통합된 제3자 서비스(Google AdSense, 카카오 애드핏 등)가 쿠키를 사용할 수 있습니다.

4-1. 쿠키의 종류와 용도

  • 광고 쿠키: 사용자에게 관련성 높은 광고를 표시하기 위해 사용
  • 분석 쿠키: 사이트 트래픽 및 사용자 동작 분석을 위해 사용
  • 기능 쿠키: 폰트 등 외부 리소스 로딩 최적화를 위해 사용

4-2. 쿠키 거부 방법

사용자는 브라우저 설정을 통해 쿠키 저장을 거부할 수 있습니다:

  • Chrome: 설정 → 개인정보 보호 및 보안 → 쿠키 및 기타 사이트 데이터
  • Edge: 설정 → 쿠키 및 사이트 권한 → 쿠키 관리
  • Safari: 환경설정 → 개인 정보 보호 → 쿠키 및 웹 사이트 데이터
  • Firefox: 옵션 → 개인 정보 → 쿠키 및 사이트 데이터

단, 쿠키를 거부하면 일부 광고 기능이 제한될 수 있으나, 사이트의 도구 기능 자체는 정상 작동합니다.

5. 개인정보의 보유 및 이용 기간

JWAY는 사용자 개인정보를 직접 수집·보유하지 않습니다. 제3자 서비스가 수집하는 쿠키 정보는 각 서비스의 정책에 따라 보유·이용됩니다:

  • Google AdSense 쿠키: 일반적으로 30일 ~ 13개월 (Google 정책 기준)
  • 접속 로그(GitHub Pages): 약 90일

6. 개인정보의 제3자 제공

JWAY는 사용자 개인정보를 제3자에게 제공하지 않습니다. 단, 다음의 경우 예외로 합니다:

  • 법령에 따라 수사기관의 정당한 요청이 있는 경우
  • 사용자가 사전에 동의한 경우

7. 개인정보의 안전성 확보 조치

JWAY는 사용자 데이터 보호를 위해 다음 기술적 조치를 취합니다:

  • HTTPS 암호화 통신: 모든 페이지가 SSL/TLS 인증서로 암호화되어 전송됩니다.
  • 클라이언트 사이드 처리: 모든 계산은 사용자 브라우저에서 처리되어 데이터가 외부로 전송되지 않습니다.
  • 최소 권한 원칙: 외부 API 호출 시(예: 환율 정보) 필요 최소한의 데이터만 사용합니다.

8. 사용자의 권리

「개인정보 보호법」 제35조부터 제37조에 따라 사용자는 다음 권리를 갖습니다:

  • 개인정보 열람 요구
  • 오류 등이 있을 경우 정정 요구
  • 삭제 요구
  • 처리 정지 요구

JWAY는 직접 개인정보를 수집하지 않으므로 위 권리 행사 대상이 일반적으로 발생하지 않습니다. 다만 광고 쿠키와 관련된 권리는 위 4-2 또는 3-2 항목을 참고하여 직접 행사하실 수 있습니다.

9. 아동의 개인정보 보호

JWAY는 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 만 14세 미만 아동이 본 사이트를 사용하는 경우 보호자의 지도하에 이용하시기 바랍니다.

10. 외부 링크 정책

JWAY는 다른 웹사이트로의 링크를 포함할 수 있습니다. 이러한 외부 사이트에서의 개인정보 처리는 해당 사이트의 정책에 따르며, JWAY는 외부 사이트의 콘텐츠나 정책에 대해 책임지지 않습니다.

11. 개인정보처리방침의 변경

본 방침은 법령·정책·서비스 변경에 따라 수정될 수 있습니다. 변경 시 본 페이지에 게시하며 중요한 변경의 경우 시행일 7일 전 공지합니다. 변경 후에도 사이트를 계속 이용하시면 변경된 방침에 동의한 것으로 간주됩니다.
